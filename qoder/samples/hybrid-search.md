# 混合检索设计

自编教学示例。本文解释实现思路，没有真实用户效果数据。

关键词检索擅长匹配术语、缩写和精确标识符；语义检索通过向量表达概念，适合用不同措辞寻找相关内容。例如用“减少模型编造事实”可以寻找讨论“幻觉”的段落。模型相似度不是事实正确性的概率。

混合检索分别取得全文候选和向量候选，再用倒数排名融合（RRF）合并排名。RRF 对每个候选累加 1 / (k + rank)，让同时出现在两条检索路径的片段获得更高优先级。融合分数只能解释排序，不能当作百分比可信度。

对于检索增强生成中的幻觉，混合检索可以补充遗漏的相关资料，但并不能替代来源核对。应检查召回段落是否真正支持问题，并阅读原文上下文。空结果也应被诚实展示。

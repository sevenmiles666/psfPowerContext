## 浏览器流程

打开首页 → 混合检索 → 核对原文 → 复制引用 / 下载 Markdown → 收藏并刷新 → 关键词空结果 → 语义检索与文档过滤 → 上传中文文件名并再次上传核对去重 → 检索含脚本的文本并验证不执行 → 手机导航、宽度与原文跳转 → 控制台检查。

页面标题正确、非空白，无框架错误覆盖层，无相关控制台/运行时错误。具体断言见 `tests/browser.mjs`。复制实际读取剪贴板；导出实际等待浏览器下载事件；收藏实际从数据库重读，不是只检查按钮颜色。

## 设计对照

参考：`design/concept.png`（内置 Image Gen 生成，**不是功能截图**）。实际：`screenshots/search-desktop.png` 和 `search-mobile.png`。已使用 `view_image` 检查原始设计图与最新实际截图。

| 对照点 | 检查与处理 |
| --- | --- |
| 容器与布局 | 244px 左导航，开放式结果列表与右侧原文栏，细分隔线；修正了初版侧栏/标题的横向偏移 |
| 文案与信息结构 | 保留品牌、导航、标题、副标题、三种检索方式和主要操作；首屏没有额外营销模块 |
| 字体层级 | 衬线大标题，较小的资料元信息，正文和操作层级分开；去掉远程字体请求以便本地使用 |
| 配色 | 白色工作面、浅灰侧栏、暖橙按钮/引用高亮；无渐变和重阴影 |
| 组件 | 小圆角输入与按钮，书形与文件图标，逐段收藏和单一原文预览 |
| 响应式 | 手机转换为顶部导航，结果与原文纵向展示，点击原文主动滚动定位；无横向溢出 |

有意差异：结果数量、段落文本、页码、收藏数和耗时取自真实运行，不硬编码成设计图的 3 条。增加了真实检索记录入口；源文件按实际文件名展示，而非统一虚构“自编示例资料”元信息。原文过长时滚动阅读，保证复制引用按钮可达。上述状态差异服务于真实功能；结构、色彩、主要文案和交互布局已按设计参考验证。

未验证：Safari / Firefox、跨用户部署、公网认证、大规模语料性能、OCR、Qoder Sites 发布及真实用户使用效果。当前范围为本机单人应用。

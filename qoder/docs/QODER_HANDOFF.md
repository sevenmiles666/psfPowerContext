# Qoder 开发与发布交接

## 先补齐实际 Qoder 开发

本目录当前是 Codex 实现的可运行原型。比赛要求主要开发在 Qoder 中完成；仅把现成代码交给 Qoder 发布网站不能满足要求。须在 Qoder 中真实开展主要功能的开发/重构/验证，留存可核对过程；不要事后伪造截图。

在 Qoder 打开仓库，确认当前为 `2026-competition-ecosystem` 分支，工作目录为 `qoder/`。可以用下面的任务说明开始真实工作，再根据实际完成情况保留记录：

```text
这是 Qoder × OceanBase 赛题的文献检索项目「知页 PaperTrail」。
现有 qoder/ 是 Codex 开发的原型，不属于 Qoder 开发记录。
请先阅读 qoder/README.md、server/、src/ 和 tests/，基于真实需求重新拆解核心流程。
在 Qoder 中实际完成主要模块的迭代与验证：
1. 扩展主题资料库，确保每条全文、向量及混合检索都严格隔离资料库；
2. 增加文献删除及对应片段、收藏的清理，处理失败恢复与一致性；
3. 增加多篇文献证据对照视图，保留每条证据的准确原文与定位；
4. 用人工标注问题集评估检索，记录真实排名与召回，不编造指标；
5. 完成接口和浏览器验收，更新文档、截图与提交材料。
不要将已有功能重新描述为你刚开发的工作；记录你实际变更的模块、命令与结果。
只改 qoder/，保留官方比赛分支祖先，禁止提交 .env、密钥、个人资料和模型缓存。
先给出明确任务拆解，然后执行、调试、验证。
```

这段提示仅是后续工作建议，不表示上述迭代已经完成，也不能替代“主要开发在 Qoder”这一比赛要求的实际达成。

过程记录请使用 [QODER_RECORD.md](QODER_RECORD.md) 的空白模板填写，并附真实会话截图/录屏、相关 commit 和实际命令输出。不要填写未执行的环节。

## 再用 Qoder Sites 创建展示网站

比赛允许网站作为作品展示与运行说明入口，不要求把本机数据库强行迁入站点。推荐网站展示真实截图、项目价值、检索流程、源码、安装与验证步骤；如果没有可公开访问的应用后端，就明确“本机部署体验”，不放假的在线体验按钮。

在 Qoder 个人账号的 Sites 新建站点，或新任务中引用 `@sites`，附上 README、验证材料与真实截图。官方流程见 [Qoder CN 站点文档](https://docs.qoder.cn/qoder/sites)。以下内容可作为建站提示：

```text
@sites 请为文献检索工具「知页 PaperTrail」创建中文项目展示网站。
依据 qoder/README.md、docs/VALIDATION.md 和真实浏览器截图，所有描述与代码现状一致。
使用白底、浅灰导航、暖橙色点缀，清晰的论文阅读风格，适配手机。
网站包含：
- 项目简介：从论文、笔记和实验记录中找段落，回到原文核对出处。
- 解决的问题：跨文件翻找耗时，检索结果缺少来源，阅读线索难保留。
- 已实现功能：PDF/Markdown/TXT 导入；关键词/语义/混合检索；资料范围筛选；
  原文页码/段落定位；收藏；带出处的 Markdown 导出；真实 seekdb 操作记录。
- 技术流程：本地多语言 MiniLM → seekdb 全文+向量候选 → 数据库 RRF → 原文引用。
- 实际截图：docs/screenshots/search-desktop.png 与 search-mobile.png，明确标注是本机演示。
- 源码链接：https://github.com/sevenmiles666/psfPowerContext/tree/2026-competition-ecosystem/qoder
- 安装与验证步骤：准确摘录 README，入口标注“本机部署体验”，不要伪造在线应用。
- 使用效果：尚无真实用户测量，明确标注，不能把功能测试次数当用户数。
- 开发记录：只引用之后在 Qoder 中真实完成的记录，不将 Codex 原型开发冒充 Qoder。
不要在网站公开账号 UID、私密文档、API Key 或数据库密码。
如果仓库为私有，说明评审需要仓库授权；不要声称匿名可查看私有源码。
```

Qoder 中检查站点后点击「发布」，再在分享设置中将个人账号站点改为「任何人都可访问」并确认。企业账号不支持公开访问。使用无痕窗口核对站点；如修改预览内容，需再次发布才能更新线上版本。上述流程依据 [Qoder CN 官方说明](https://docs.qoder.cn/qoder/sites)，界面文字以当前产品为准。

最终把真实 URL、Qoder UID、评审可访问的仓库地址及选定 commit 填入 `SUBMISSION.md`。公开网站成功不代表私有仓库自动向评审开放。

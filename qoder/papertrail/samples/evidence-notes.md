# 混合检索与证据评估

自编教学示例：本笔记用于演示 seekdb 的全文索引、向量索引与 RRF 排名融合，不是学术论文。

关键词检索适合查找明确术语、缩写和编号。中文全文索引使用 IK 分词，因此查询句子与实际匹配词片并不完全相同；遇到空结果时，可以缩短为更具体的术语再试。

语义检索使用本地多语言模型把文本编码为向量，再通过 HNSW 余弦近邻寻找相关段落。它能够召回措辞不同的内容，但最邻近不代表内容正确，向量距离也不能转换为事实可信度百分比。

混合检索分别取得全文与向量候选，再使用倒数排名融合。RRF 对每个分支的名次计算 1/(60+rank) 并求和，关注候选在各分支中的相对位置，而不是把两个不同量纲的分数直接相加。

评估检索质量时，应逐条检查返回片段是否真正支持问题，并记录资料库、文献范围、模型版本、片段 ID 和耗时。没有匹配时要展示空状态，不生成看似合理的回答。

这是一段用于验证长文本切片与来源定位的自编内容。实际整理研究资料时，往往需要同时查看方法、数据、限制和结论，而不是只读取检索命中的短句。知页保留完整源文本，并为每个切片记录原文字符起止位置，因此读者可以检查命中句前后的限定条件。长段落会被拆成多个连续片段，同一段落中的片段共享段落编号但拥有不同的片段编号。这样既能控制索引文本长度，也能在原文预览中定位当前片段，避免把截断后的文字误认为完整论述。例如，当某项方法只在特定数据集、语言或参数设置下得到观察结果时，摘出一句肯定描述可能会改变作者原本的意思。读者需要向前查看实验范围，向后查看失败案例和限制说明，再决定这段材料是否支持自己的笔记。检索系统可以提供入口，却不能替代这一判断过程。为了验证这一交互，本段继续加入方法核对、引用复核和阅读清单的使用场景，让切片长度超过单篇上限。测试应当检查每个片段都能映射回连续的原文区间，相邻片段之间没有意外遗漏，最后一片能够到达段落末尾；同时还应检查原文预览没有执行资料中的 HTML 或脚本。以上文字只是为了构造可重复的教学验收条件，不代表任何真实研究结论。
